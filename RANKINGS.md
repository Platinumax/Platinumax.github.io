# Как устроены подборки Vlas

Адрес плагина остаётся прежним: `https://platinumax.github.io/vlas.js`.

Первые четыре ряда: популярность за неделю, месяц, полгода и год. Пятый и
последующие ряды из старой версии сохранены под ними. Популярность в готовой
выборке берётся из Trakt (число зрителей за период). При недоступности этой
выборки используются данные о трендах или популярности TMDB, и название ряда
честно показывает источник и смысл периода.

Оценка TMDB **не участвует** в проверке, сортировке или отображении карточек.
Для каждого кандидата плагин запрашивает реакции CUB через встроенный API
Lampa: «Огонь» (`fire`), «Нравится» (`nice`), «Нормально» (`think`),
«Скучно» (`bore`), «Плохо» (`shit`). Балл на карточке вычисляется из них:

`(10 × fire + 8 × nice + 5 × think + 2 × bore + 20 × 5) / (все реакции + 20)`.

Фильмы с менее чем 15 реакциями не показываются. Если реакций 30 и больше,
фильм исключается при доле «Скучно» + «Плохо» от 38 % или доле «Плохо» от 20 %
(при 20 и более таких реакциях). Также нужны перевес положительных реакций и
балл не ниже 5,6. Так фильм с тысячей «Плохо» отсекается независимо от
оценки TMDB. Жанр ужасов (TMDB ID 27) скрывается во всех рядах, включая
триллеры и фантастику. При недоступных реакциях карточки без проверки
не выводятся. Это может сделать ряды короче или пустыми.

Плагин меняет балл **на карточке своей главной страницы**. На странице фильма
сама Lampa может показывать собственные рейтинги, в том числе TMDB.

Ряды добирают кандидатов с нескольких страниц каталога, пока не наберут до
14 проверенных фильмов или не достигнут лимита в 75 кандидатов и пяти страниц.
Запросы реакций выполняются одновременно не более чем для пяти фильмов; их
результаты хранятся шесть часов, чтобы повторное открытие главной было быстрее.
Для редких подборок допускается повтор уже показанного фильма, если без него
ряд остаётся коротким. Когда CUB недоступен или подходящих фильмов не хватает,
ряд может содержать меньше 14 карточек.

Ряд «Новые фильмы» охватывает только текущий календарный год; фильму должно
быть не меньше 14 дней с даты релиза. Недельный ряд без Trakt называется
«В тренде на этой неделе».

## Включение Trakt

1. Получить клиентский ID приложения в Trakt и токен TMDB API Read Access.
2. В репозитории GitHub открыть **Settings → Secrets and variables → Actions**;
   добавить секреты `TRAKT_CLIENT_ID` и `TMDB_API_TOKEN`. Не размещать ключи в
   `vlas.js` или в публичных файлах.
3. На вкладке **Variables** добавить `RANKINGS_ENABLED` со значением `true`.
4. Запустить **Actions → Refresh movie rankings → Run workflow**. Ежедневное
   обновление запланировано на 05:15 UTC; результат сохраняется по адресу
   `https://platinumax.github.io/data/rankings.json`.

Если секретов нет, данных нет или они старше 72 часов, плагин автоматически
показывает подборки TMDB: недельные тренды и **популярные
сейчас среди фильмов, вышедших** за месяц, полгода и год. Это разные показатели.

Полугодовой ряд Trakt рассчитывается по сумме ежедневных показателей за 180
последовательных дней. До накопления этой истории используется подборка TMDB.
Повторные просмотры одним человеком в разные дни при суммировании могут
учитываться несколько раз: это активность просмотров, а не число уникальных
зрителей за полгода. Данные Trakt относятся ко всему миру; наличие фильма с
русской озвучкой эти источники не подтверждают.

Используются официальные [Trakt API](https://docs.trakt.tv/reference/getmovieswatched)
и [TMDB API](https://developer.themoviedb.org/reference/movie-details).
Letterboxd не участвует: его [правила](https://letterboxd.com/legal/terms-of-use/)
запрещают автоматический сбор данных, а [API](https://letterboxd.com/api-beta/)
не предоставляют для личных рекомендательных проектов.
