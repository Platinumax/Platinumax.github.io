# Как устроены подборки Vlas

Адрес плагина остаётся прежним: `https://platinumax.github.io/vlas.js`.

Первые четыре ряда: популярность за неделю, месяц, полгода и год. Пятый и
последующие ряды из старой версии сохранены под ними. Для Trakt популярность
означает количество уникальных зрителей за выбранный период, а качество —
рейтинг TMDB с поправкой на количество голосов. Наш балл Vlas для сортировки:

`0.8 × (0.7 × (1 − позиция / размер списка) + 0.3 × log(1 + зрители) / log(1 + максимум зрителей)) × 10 + 0.2 × (голоса × рейтинг TMDB + 650 × 6.5) / (голоса + 650)`.

Цифра рейтинга на карточке **остаётся оценкой TMDB**. Плагин использует
собственный балл только для порядка карточек. Он не равен оценке фильма.

## Включение Trakt

1. Получить клиентский ID приложения в Trakt и токен TMDB API Read Access.
2. В репозитории GitHub открыть **Settings → Secrets and variables → Actions**;
   добавить секреты `TRAKT_CLIENT_ID` и `TMDB_API_TOKEN`. Не размещать ключи в
   `vlas.js` или в публичных файлах.
3. На вкладке **Variables** добавить `RANKINGS_ENABLED` со значением `true`.
4. Запустить **Actions → Refresh movie rankings → Run workflow**. Ежедневное
   обновление запланировано на 05:15 UTC; результат сохраняется по адресу
   `https://platinumax.github.io/data/rankings.json`.

Если секретов нет, данных нет или они старше 72 часов, плагин автоматически
показывает подборки TMDB с точными названиями: недельные тренды и **популярные
сейчас среди фильмов, вышедших** за месяц, полгода и год. Это разные показатели.

Полугодовой ряд Trakt рассчитывается по сумме ежедневных показателей за 180
последовательных дней. До накопления этой истории используется подборка TMDB.
Повторные просмотры одним человеком в разные дни при суммировании могут
учитываться несколько раз: это активность просмотров, а не число уникальных
зрителей за полгода. Данные Trakt относятся ко всему миру; наличие фильма с
русской озвучкой эти источники не подтверждают.

Используются официальные [Trakt API](https://docs.trakt.tv/reference/getmovieswatched)
и [TMDB API](https://developer.themoviedb.org/reference/movie-details).
Letterboxd не участвует: его [правила](https://letterboxd.com/legal/terms-of-use/)
запрещают автоматический сбор данных, а [API](https://letterboxd.com/api-beta/)
не предоставляют для личных рекомендательных проектов.
